# Repositório de UI/UX + projetos

- **[nazario-massas/](nazario-massas/README.md)** — e-commerce premium de pizzas, massas e bebidas (loja + painel administrativo).
- **[pituco/](pituco/README.md)** — série infantil em animação 2D (YouTube Shorts): personagem, roteiro, animação SVG, áudio e render para MP4.
- **LibreUIUX-Claude-Code-main/** — kit de UI/UX para Claude Code (plugins, agentes, skills).
- **ui-ux-pro-max-skill/** — skill de inteligência de design (estilos, paletas, tipografia por setor).
- **ruflo/** — plataforma de orquestração multiagente.
- **.claude/skills/** — skills ativas para as sessões do Claude neste repositório.

Instruções para o Claude: [CLAUDE.md](CLAUDE.md).

## Publicar na Vercel

Importe este repositório na Vercel e clique em **Deploy** — o `vercel.json` da raiz
já aponta para `nazario-massas/`. Loja em `/`, painel em `/#admin`.
